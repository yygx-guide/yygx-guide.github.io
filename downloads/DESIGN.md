# 下载站维护规范

本页位于既有导航仓库的 `/downloads/`。发布时只更新本目录、镜像同步脚本及相关测试；保留导航页其它内容。

## 目标用户

- 兼顾中国大陆与台湾用户。界面文案分别编写简体与繁体版本，繁体使用「裝置、安裝檔、檔案驗證、重新整理」等自然用词。
- 字体使用系统字体，图片与脚本由同一 GitHub Pages 站点提供，不依赖外部字体、CDN 或翻译接口。
- 安装包保留原站备用下载入口。不能以某处网络测试通过，代替大陆与台湾不同网络的实际可用性测试。

## 视觉依据

- 首要参考：Drive「初代观星app使用文件 / 观星模拟器.apk」中的视觉素材。
- 网站参考：https://yygx-guide.github.io/ ，共享其 `style.css`、`assets/` 中已公开的品牌图像。
- 宣纸米白、墨黑、松绿、低饱和金色与适量朱砂色；宋体标题、小圆角、细边框与克制留白。
- 两个平台的下载按钮保持一致，不增加右侧大型装饰图标、营销标语或模板式介绍卡。

## 内容与交互

- 页面名称：烟雨助手 · 下载网站。明确标注镜像网站，来源单独列出。
- 安装包当前版本从 data.json 读取；打开页面时读取最新状态，失败保留服务器已生成的可用链接。
- 更新说明按版本合并，相同安卓与 Windows 说明只展示一次；差异确实存在时保留平台标识。
- 默认显示最近三个已核实版本，更早记录通过原生 details 展开；保存完整已观察历史，不编造缺失版本。
- 简繁、明暗与历史展开只在浏览器运行，不调用 AI。自动同步继续使用 GitHub Actions 的普通 Python 程序。
