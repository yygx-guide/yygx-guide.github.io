观星导航 · APP 下载弹窗版

【先预览】
1. 解压完整工程压缩包。
2. 打开解压后的文件夹，双击 index.html，即可在浏览器里查看网页。
3. 试一下右上角「简体 / 繁體」和「护眼」按钮，以及各卡片的展开功能。

【平时改文字：用记事本就够了】
1. 改首页小提示（现在是「使用教程与相关说明持续更新」）：
   右键 config.js → 打开方式 → 记事本，按 Ctrl+F 搜索 homepageNotice。
   只修改英文单引号之间的中文内容，保留引号、逗号和其他符号，按 Ctrl+S 保存。

2. 改网页标题、卡片名称、描述、常见问题、弹窗里的普通说明：
   右键 index.html → 打开方式 → 记事本，按 Ctrl+F 搜索要改的中文，替换文字，按 Ctrl+S 保存。
   注意：只改标签之间的文字，不要删掉 < > 里面的 HTML 代码。

3. 改授权状态弹窗的动态文案、三个系统弹窗的动态提示：
   用记事本打开 script.js，搜索 salesCopy 或 platforms。
   只改引号中的中文，别改函数、变量名和标点。
   当前 salesPaused: true，代表不开放新授权购买或预订；实际恢复之前不要改成 false。

4. 修改首页「观星 APP 下载」的链接：
   用记事本打开 config.js，找到 appDownloadUrl: '',
   把两个英文单引号之间改成真实下载地址，例如：
   appDownloadUrl: 'https://example.com/download',
   保存后，点击首页「观星 APP 下载」会先出现说明弹窗，点击「前往下载」才打开新页面。
   留空时弹窗显示「下载地址待设置」，不会跳转到假网址。
   弹窗里「下载链接打不开怎么办」的文字在 index.html 中修改。

5. 改教程链接、闲鱼店铺、交流群链接：
   用记事本打开 config.js，找到 introUrl、fullGuideUrl、storeUrl、communityUrl、tutorialUrls。
   把英文单引号中的网址换成新网址，保存。
   链接留空的入口可能提示「待设置」或使用默认完整教程。

6. 简繁切换会自动处理绝大多数新文字，不需要分别编辑两套网页。
   极少数多音多义字转换后可能不够自然，修改后最好亲自点一下「繁體」检查。
   lang-map.js 是本地转换字表，一般不需要修改；style.css 控制颜色和布局。

【把更新发布到原来的 Cloudflare 网站】
1. 先在自己电脑双击 index.html，确认修改后的效果正常。
2. 登录 Cloudflare → 左侧「计算」→「工人与侍从（Workers & Pages）」→ 找到你已经发布的观星导航应用。
3. 打开原来的应用，点击右上角「新部署」；按页面提示选择上传静态文件或文件夹。
4. 把解压文件夹里的所有文件和 assets 文件夹一起上传，注意 index.html 必须在根目录。
   本版本有 index.html、config.js、script.js、style.css、lang-map.js、assets 文件夹，以及本说明文本。
5. 检查文件清单，再点「部署」。等待发布成功。
6. 继续使用原来的 workers.dev 网址，不要新建另一个应用。
7. 如果打开后仍是旧内容，先按 Ctrl+F5 强制刷新，或用手机无痕浏览器再看。

【特别注意】
- 不要只上传 index.html，否则页面样式、图片和简繁切换可能失效。
- 你本地改了文件，并不会自动同步到线上；每次改完都需要重新部署。
- config.js 和 lang-map.js 会被访客读取，不要把密码、私密授权码、API 密钥写进去。
- 页面是纯静态导航，不会主动采集账号或存档；请确认有权公开使用软件相关图标和素材。

【简繁切换与飞书链接】
导航站上的「简体 / 繁體」仅转换本网站内容，无法修改外部飞书页面。
最省事的做法是保持一份飞书原文，让需要繁体的读者使用 Edge/Chrome 的网页翻译功能（可选目标中文繁體，具体以浏览器支持为准）。
如希望任何访客点击后默认阅读繁体，需要另外维护繁体版飞书文档并为它设置独立链接，或未来将教程迁移到自己的网页；不建议用不稳定的第三方翻译网址自动跳转。
