观星导航｜05「使用问题」目录弹窗版

本次修改：
- 05 卡片改为「使用问题」，点击弹出目录窗口，不再在首页展开问答。
- 弹窗内的四个目录：下载/安装/更新问题、授权码验证失败问题、导出存档失败问题、软件使用问题。
- 各目录可以点击，默认打开你原来飞书的《05｜常见问题》文档。
- 如果要点击后直接跳到对应章节，把该章节的完整链接填写进 config.js 的 faqCategoryUrls。未设置时会自动使用 faqUrl。
- 保留首页其他四张卡片、销售暂停状态、其他原有链接、亮色/护眼主题及简繁切换。

上传 GitHub Pages：
1. 解压 ZIP。
2. 在 GitHub 仓库 yygx-guide/yygx-guide.github.io 上传网站文件（不是 ZIP 文件）。
3. 提交 Commit changes，部署成功后强制刷新网页（Ctrl+F5）。

如果仓库中已有原网站和 assets 文件夹，也可以仅上传本次的 index.html、style.css、script.js、config.js 四个文件，其它文件不用换。
